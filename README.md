# Pokémon Hub · 宝可梦全渠道信息系统

课程小组作业：以宝可梦官方门户的公开内容结构为参考，制作一个**只输入网址即可访问**的消费者门户与管理经营驾驶舱。网站为纯前端静态站点，不需要后端、数据库或安装依赖。

## 1. 立即访问

**GitHub Pages 地址：`https://<你的GitHub用户名>.github.io/pokemon-hub/`**（部署后替换）  
**本地预览：<http://127.0.0.1:8080/>**

本地静态服务器已运行。如服务器停止，双击 `start-server.bat`（或运行 `start-server.ps1`）即可重新启动。

## 3. 已实现功能

### 消费者端

- 与宝可梦官网一致的六大内容入口：资讯、电视动画/电影、商品、应用程式、游戏、卡牌
- 右上角宝可梦图鉴入口；52 只宝可梦的搜索、属性/世代筛选、排序、收藏和详情
- 20 款卡牌商品、卡套/卡册/卡砖/整盒补充包等款式；消费者 / 管理者双角色登录
- 全局搜索（Ctrl/Cmd + K）：跨资讯、图鉴、商品、游戏检索
- 商品分类筛选、价格/热度排序、商品详情、收藏、购物袋数量、优惠码 `PIKA10`、演示结算
- 资讯分类与关键词筛选、加载更多、文章详情
- 动画剧集/剧场版详情弹窗；应用、游戏详情弹窗
- 移动端抽屉导航、响应式布局、Esc 关闭弹层、滚动揭示动画

### 管理者端（`admin.html`）

- **经营总览**：真实财务 KPI、五年营收/利润趋势、业务结构、渠道构成、运营提醒、热销商品、动态
- **资讯运营**：发布量、浏览量、阅读时长、订阅转化、内容类型占比、明细与洞察
- **动画 / 影视**：播放量、完播率、授权收入、会员观看占比、作品表现
- **商品电商**：GMV、订单、客单价、支付转化、渠道结构、库存预警、商品明细
- **应用程式**：矩阵 MAU、下载、D30 留存、应用内收入、应用占比
- **游戏业务**：活跃玩家、数字版销量、DLC 渗透、平台结构
- **卡牌业务**：卡牌销售额、赛事场次、活跃牌手、售罄率、扩充包表现
- **图鉴运营**：图鉴 MAU、查询次数、收藏转化、热门属性与条目
- **会员增长**：会员总数、新增、复购、LTV、等级结构与会员明细
- **财务中心**：FY2022—FY2026 公开财务数据、损益/资产负债摘要、关键比率、来源链接、CSV 导出、打印/PDF
- **系统设置**：演示账号、权限、数据边界、导出本地演示数据、重置数据

所有业务板块都能从侧边栏点击切换，支持通过 `admin.html#finance` 等锚点直达。表格支持当前页搜索过滤，业务页和财务页均支持 CSV 下载。

## 4. 信息系统架构

架构图以五个层次呈现：

1. **用户触点**：消费者、移动端访客、经营管理者、外部触点
2. **体验与渠道**：门户、资讯、动画、商品、应用、游戏、卡牌、图鉴
3. **业务能力**：CMS、商品与订单、会员与身份、搜索与推荐、卡牌与赛事、经营分析、财务与报表
4. **数据与集成**：静态内容、localStorage、PokéAPI/官方素材、公开财务、导出与打印
5. **支撑与治理**：设计系统、响应式与可访问性、权限与审计、隐私与免责声明、版本与交付

- `assets/architecture.png`（1600×1090，便于插入 Word/PPT）

## 5. 是否只有前端？——是

老师提供的网页样例为零售后台式网页模板。由于 Gemini 分享链接需要 Google 登录才能访问，公开抓取会被重定向，本次按“零售信息系统后台的常见功能”进行对标：登录与角色、经营仪表盘、内容/商品/订单/会员管理、报表与设置；再结合宝可梦官网的六大内容入口与图鉴重新设计。

本作品**没有后端**：

- 页面由 Python 静态文件服务器提供，只有 HTML/CSS/JS 和图片资源
- 没有 API、数据库或服务端会话
- 账号校验是前端硬编码演示逻辑
- 购物车、收藏、订单、登录状态保存在 `localStorage`
- 财务数据是随站点发布的静态数据，不是实时接口
- 不提供真实支付、票务、会员或赛事报名

因此，它能完整展示信息架构、交互与管理者视角，但不能作为生产交易系统。架构图中的“生产扩展”列出了真实上线时需要补充的 API Gateway、微服务、数据库、OIDC、RBAC、数据仓库与可观测性。

## 7. 运行方式

推荐：双击 `start-server.bat`，浏览器会自动打开 <http://127.0.0.1:8080/>。

手动运行（任选其一）：

```powershell
# Python
python -m http.server 8080 --bind 127.0.0.1

# Node.js
npx serve -l 8080 .
```

> 不建议直接双击 HTML 文件。通过 `file://` 打开时，部分浏览器的 localStorage 行为与相对路径可能不一致，使用本地服务器最稳定。

站点不依赖构建工具、npm 包或网络接口。除外部引用链接外，所有页面与资源均随站点本地提供。
