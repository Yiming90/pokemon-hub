FRONTEND ONLY

关于“只有前端”

结论 本站没有后端

页面由静态文件服务器提供，输入网址即可访问。没有 API 服务、数据库或服务端登录；账号校验、购物车、订单与收藏均在浏览器内完成。这样可以完整展示交互与信息架构，同时避免真实交易与隐私风险。

  • 可直接部署到 GitHub Pages / Netlify 等静态托管
  • 本地可用任意静态服务器运行，无需安装依赖
  • 数据刷新后仍保留（同一浏览器）
  • 清除浏览器数据会重置演示状态

说明 为什么仍然像“系统”

通过角色路由、独立管理端、业务指标建模、真实财务数据和数据导出，把“网页”提升为“信息系统的界面层”。架构图进一步说明：生产化时哪些层需要替换为服务。

  • 消费者与管理者两套信息架构
  • 业务指标与财务指标分离标注
  • 可下载 CSV / SVG / ZIP 交付
  • 无需后端即可演示完整流程
